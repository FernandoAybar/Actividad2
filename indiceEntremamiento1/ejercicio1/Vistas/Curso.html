Administración de Servidores con Windows Server

Estudios / Descripción del Programa

Modalidad Virtual

Este curso provee el conocimiento necesario para entender e identificar las tareas involucradas en la administración de servidores basados en Windows Server. No requiere tener nociones previas en estos tipos de sistemas operativos, ya que está diseñado para proveer desde una descripción general de conceptos básicos hasta su implementación.
